## 🚀 Introduction  

Studemeter leverages **IoT, machine learning, and signal processing** to detect students' **emotions and cognitive load** in real time, helping educators enhance learning experiences.  

## 🔥 Why Studemeter?  

### **Challenges**  
❌ Hard to assess cognitive load & emotions  
❌ Limited personalized student support  
❌ No real-time engagement tracking  

### **Solutions**  
✅ **Live emotion & cognitive insights**  
✅ **GSR sensors + ML for accuracy**  
✅ **Personalized learning recommendations**  

---

## 🛠️ Tech Stack  

- **Frontend:** Next.js (React, TypeScript, SCSS)  
- **ML Model:** Support Vector Machine (SVM)  
- **IoT Sensors:** Galvanic Skin Response (GSR)  
- **Data Processing:** Low-pass filtering, phasic signal isolation

## 📡 Data Collection & Processing  

### **1️⃣ GSR Data Collection**  
- Wearable sensors track **skin conductance**.  
- Collected during **various learning activities**.  
- Uses **external datasets** for model improvement.  

### **2️⃣ Preprocessing & Feature Engineering**  
- **Noise Reduction:** 5Hz low-pass filter  
- **Phasic Signal Extraction:** Rapid fluctuation detection  
- **Feature Engineering:** Amplitude, frequency, variation analysis

## 🤖 Machine Learning  

**Model:** Support Vector Machine (SVM)  
- **Training:** Labeled student emotion & cognitive load data  
- **Validation:** Cross-validation for generalization
